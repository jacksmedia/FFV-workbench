Key technical change: Because sprite data now spans the EB/EC bank boundary, the battle and menu routines compute the bank dynamically:
asm
ADC #$E3E0    ; add base offset, sets carry if overflow
STA $76       ; store 16-bit offset
LDA #$EB      ; base bank
BCC +2        ; skip if no carry
INC A         ; A = $EC if carry
STA $78       ; store computed bank

The dispatch routine now handles both MVN $7E,$EB and MVN $7E,$EC cases.
