# EquipMenuDeluxe Handoff - 2026-08-29

## Goal
Display weapon element icons, armor element halve/immune icons, and status immunity icons in the lower-left blank area of FFV's Equip menu (replicating Crow's FF4 enhancement).

## Current Status: BLOCKED on Tilemap Addressing

### What Works
- **Hook mechanism**: JSL at C2/CB86 → E0/8000 executes without crashing
- **Code structure**: v1 has full element/status reading logic, v2_diag has simple test writes
- **Assembler**: asar compiles both versions cleanly

### What Doesn't Work Yet
- **No visible tiles**: Neither v1 nor v2_diag produce any visible output on the Equip menu
- **Tilemap writes not appearing**: Even hardcoded "ABCDEFGH" and "TEST" strings don't show

---

## Key Discovery from Mesen Tilemap Viewer

User provided screenshot showing:
- Helmet icon at Column 2, Row 15 → Tilemap address **$7E:7790**
- VRAM tilemap address shown as $19E2

Calculated buffer base:
- Offset for (row=15, col=2) = 15×64 + 2×2 = $3C4
- Base = $7790 - $3C4 = **$73CC**
- Full address: **$7E:73CC**

v2_diag uses this address but still produces no visible output.

---

## Hypotheses for Next Session

### 1. Timing Issue
The menu might refresh/redraw the tilemap AFTER our hook runs, overwriting our changes.
- **Test**: Hook at a LATER point in the menu loop, or find where the DMA transfer happens

### 2. Wrong Tilemap Layer
FFV menus may use multiple BG layers. We might be writing to the correct buffer but wrong layer.
- **Test**: Check which BG layer the menu uses, verify VRAM tilemap address matches

### 3. Need to Trigger VRAM Update
Writing to the WRAM buffer alone may not be enough - there may be a DMA routine that copies buffer to VRAM.
- **Test**: Find and call the VRAM update routine after our writes

### 4. Tilemap Base Still Wrong
The $73CC calculation assumes a standard 32×32 tilemap starting at row 0. Menu might use scroll offsets.
- **Test**: Try writing directly to $7E:7790 (helmet's exact address) to overwrite it

### 5. Different Menu State
The screenshot was from the item selection popup. Main Equip screen might use different addresses.
- **Test**: Get tilemap address from main Equip screen (not popup)
